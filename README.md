# CSC345 – House Prices Prediction (Team Rhapsody)
This repository contains our group project for CSC345 Data Science, where we participated in the Kaggle House Prices: Advanced Regression Techniques competition. The main goal of the project is to predict house sale prices using a structured dataset with various property, neighborhood, and quality features. We treat this repository as both our competition workspace and a record of our full data science workflow, from early experiments to our final submission.

The project is organised into two main phases: a Second Presentation folder and a Final folder. The Phase 2 folder contains our first round of baseline models and data preparation such as exploratory data analysis, data cleaning steps, feature engineering. The Final folder focuses on the polished pipeline that we used for our best Kaggle submission, including the main training scripts or notebooks, tuned models, and the final prediction output. 

Across both phases, we follow a typical data science process: loading the Kaggle dataset, handling missing values, encoding categorical variables, scaling or transforming skewed features, and evaluating different regression models. We compare several algorithms and configurations, use validation scores to guide improvements, and refine our feature set and model choices based on evidence rather than guesswork. The final setup in the Final folder represents the version we judged most stable and accurate for the competition.

To use this repository, clone it and open the notebooks or Python scripts in the phase you are interested in. You can follow the steps in Phase 2 to understand how our ideas evolved, or go directly to the Final folder to see the final version that generates predictions for Kaggle competition. This project was created for learning purposes, but we hope it also serves as a clear example of how to structure a small, team-based data science project from classroom assignment to leaderboard submission.
